# Temperature Converter Tool 🌡️

A modern, responsive, and dynamic web-based Temperature Converter application. It allows users to convert temperature values between Celsius, Fahrenheit, and Kelvin units instantly with a clean dark-themed user interface.

---

## 🚀 Overview & Concept

The **Temperature Converter Tool** provides a fast and intuitive way to calculate temperatures across different scientific and standard units. Built with modern JavaScript logic, it takes user input in a selected unit and immediately displays accurate converted results for all three major temperature scales.

---

## ✨ Key Features

- **Multi-Unit Conversion:** Converts input values seamlessly between:
  - Celsius (°C)
  - Fahrenheit (°F)
  - Kelvin (K)
- **Instant Result Display:** Clears ambiguity by showing converted metrics across all scales simultaneously in a dedicated output panel.
- **Modern Dark UI:** Stylish dark-themed UI card featuring smooth glowing borders and clean input form design.
- **Input Validation & Clean Controls:** Styled input field, dropdown menu selection, and a prominent "Convert Now" button.
- **Responsive Layout:** Optimized for desktop, tablet, and mobile screens.

---

## 🛠️ Technologies Used

- **HTML5:** Semantic form inputs, layout containers, and dropdown selectors.
- **CSS3:** Custom dark theme styling, glowing card borders, custom inputs, and modern typography.
- **JavaScript (JS):** Core mathematical conversion formulas, DOM manipulation, and dynamic result rendering.
