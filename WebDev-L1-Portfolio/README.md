# Personal Portfolio Website 🌐

A sleek, responsive, and modern personal portfolio website built to showcase my web development skills, academic achievements, technical credentials, and featured projects.

---

## 🚀 Overview & Concept

This portfolio serves as a central hub for my professional profile as an Information Systems student and tech enthusiast. It bridges the gap between creative Front-End Web Design and secure backend workflows, featuring dark/light theme options, dynamic project cards, structured skills tables, and certified credentials.

---

## ✨ Key Features

- **Hero & Bio Section:** Profile avatar, glowing typography, and a comprehensive summary of my background in Web Development, Cybersecurity, Sales, and Automation.
- **Skills & Technical Matrix:** Categorized table breakdown covering Web Development, Programming (Python 3, RegEx, Automation), Tools (GitHub, MS Office), and Business/Sales skills.
- **Certified Credentials:** Highlighted achievements and certificates from the Ministry of Higher Education and Ministry of Youth & Sports.
- **Featured Projects Gallery:** Interactive project cards displaying various web apps and landing pages with direct links to view projects.
- **Theme Switcher:** Dark and Light mode toggle integrated into the navigation bar.
- **Get In Touch (Contact Section):** Direct links for email contact and GitHub profile access.

---

## 🛠️ Technologies Used

- **HTML5:** Semantic structure, accessible content layout, and clean document hierarchy.
- **CSS3:** Custom glowing neon effects, responsive design grid/flexbox, dark/light theme variables, and polished UI cards.
- **JavaScript (JS):** Dynamic theme switching functionality and interactive UI controls.
