# Login & Authentication UI 🔐

A modern, responsive, and interactive user authentication interface built with HTML5, CSS3, and JavaScript. It features seamless tab switching between Login (Sign In) and Registration forms within a clean, dark-themed UI.

---

## 🚀 Overview & Concept

The **Login & Authentication UI** provides a front-end user login and registration template. Designed with glassmorphism aesthetics and glowing neon accents, it offers a smooth, single-page user experience for switching between authenticating existing users and registering new accounts.

---

## ✨ Key Features

- **Interactive Tab Navigation:** Smooth JavaScript-powered tab switching between **Register** and **Login** forms without page reloads.
- **Login (Sign In) Form:**
  - Username or Email input field.
  - Password input field.
  - Primary "Sign In" call-to-action button.
- **Modern Dark Aesthetic:** Clean UI card featuring glowing cyan borders, styled inputs, and high-contrast typography.
- **User-Centric Input Fields:** Custom-styled placeholders and focused input indicators for better UX.
- **Fully Responsive Layout:** Centered, adaptable card layout optimized for all device screens.

---

## 🛠️ Technologies Used

- **HTML5:** Semantic form elements, tabs layout structure, and accessible input fields.
- **CSS3:** Custom dark theme variables, glowing borders, smooth transitions, and form styling.
- **JavaScript (JS):** Event listeners for interactive tab switching and form view toggling.
