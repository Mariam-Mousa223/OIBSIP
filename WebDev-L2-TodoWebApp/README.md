# Daily To-Do List Web Application 📝

A sleek, interactive, and dark-themed web application designed to help users track, manage, and organize their daily tasks efficiently in real-time.

---

## 🚀 Overview & Concept

The **Daily To-Do List App** provides a streamlined productivity interface built with Vanilla JavaScript logic. It enables users to create new tasks, separate pending items from completed ones, track task counts dynamic counters, and maintain a clear breakdown of daily goals.

---

## ✨ Key Features

- **Task Input & Creation:** Intuitive input field with an inline "Add Task" dynamic button.
- **Categorized Task Management:**
  - **Pending Tasks:** Displays active tasks awaiting completion with dynamic counter badges (`0 Pending`).
  - **Completed Tasks:** Automatically moves finished tasks to a dedicated completed list with dynamic status badges (`0 Completed`).
- **Empty State Feedback:** Displays friendly messaging and emoji indicators when no tasks are present in either category.
- **Dynamic Real-Time Counters:** Automatically updates task counts as new tasks are added, completed, or removed.
- **Modern Dark/Neon UI:** Eye-catching glassmorphism styling, glowing purple card borders, and bright action buttons for an engaging user experience.

---

## 🛠️ Technologies Used

- **HTML5:** Semantic layout structure, input fields, badges, and list containers.
- **CSS3:** Custom neon glow effects, modern gradient background, flexbox alignment, and badge styling.
- **JavaScript (JS):** Dynamic DOM manipulation, task state management, dynamic counter updates, and event listeners.
