# Interactive Calculator App 🧮

A modern, responsive, dark-themed web calculator built with HTML5, CSS3, and JavaScript. It provides a clean user interface to perform standard arithmetic operations quickly and efficiently.

---

## 🚀 Overview & Concept

The **Calculator App** offers an intuitive digital calculator experience right in the browser. Designed with a sleek dark aesthetic, distinct color-coded operation buttons, and real-time JavaScript evaluation, it allows users to perform basic calculations, clear entries, or backspace characters effortlessly.

---

## ✨ Key Features

- **Standard Arithmetic Operations:** Supports addition (+), subtraction (-), multiplication (×), and division (÷).
- **Clear & Backspace Controls:**
  - **`C` Button:** Resets the entire calculator display screen.
  - **Backspace Button:** Removes the last entered character for quick corrections.
- **Distinct Color-Coded Keypad:**
  - **Red Accent:** Clear & Backspace action keys.
  - **Cyan/Blue Accent:** Mathematical operators and the primary `=` button.
  - **Dark Glass Buttons:** Number keys for high contrast and readability.
- **Responsive & Centered Layout:** Beautifully aligned dark card layout with glowing borders.

---

## 🛠️ Technologies Used

- **HTML5:** Semantic button grid layout and display screen markup.
- **CSS3:** Grid/Flexbox positioning, dark theme UI, rounded buttons, and glowing neon box-shadows.
- **JavaScript (JS):** Event listeners, mathematical calculation logic, dynamic display updates, and string manipulation.
